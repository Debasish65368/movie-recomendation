Overview

A Movie Recommendation System built with Python, FastAPI, Streamlit, and Machine Learning. It recommends movies based on content similarity using NLP techniques and a dataset of 45,000+ movies.

Integrates with the TMDB API to fetch movie posters, ratings, descriptions, and metadata in real time.


Features


🎯 Content-Based Movie Recommendations
🧠 NLP-Based Similarity Matching
🔍 Real-Time Movie Search
🎞️ TMDB API Integration
⚡ Interactive Streamlit Interface
🚀 FastAPI Backend
📈 Trending Movies Section



Tech Stack


🐍 Language — Python
⚙️ Backend — FastAPI
🖥️ Frontend — Streamlit
📊 Data Processing — Pandas, NumPy
🤖 ML / NLP — Scikit-Learn, TF-IDF Vectorization, Cosine Similarity
🎞️ API — TMDB API
🗂️ Version Control — Git & GitHub



How It Works


Input — User searches for a movie title
Vectorize — Movie metadata is transformed using TF-IDF
Match — Cosine similarity finds the closest content matches
Fetch — TMDB API enriches results with posters and metadata
Display — Streamlit renders recommendations interactively
